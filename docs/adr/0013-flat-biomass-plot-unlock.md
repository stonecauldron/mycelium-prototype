# Plots unlock at a flat biomass cost

The Nursery has four Plots (one starts unlocked); remaining Plots cost a flat 8 kg each, same sticker as a Squad slot, bought in order. Quadratic `4n²` made later Plots unreachable in a 10-day Run — four Plots is the throttle, not the price ladder. A 4 kg unlock was rejected so Nursery width competes with Squad width; repeatable Nursery spend stays plant / Shop / Fertilizers / Mutations.
