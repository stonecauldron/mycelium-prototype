# Cap mutation species variations

Each sheet contains two species concepts. The top row is the first species and the bottom row is the second; Child is left and Adult is right.

- **Death:** destroying angel (*Amanita virosa*) / funeral bell (*Galerina marginata*)
- **Inky:** magpie inkcap (*Coprinopsis picacea*) / hare's-foot inkcap (*Coprinopsis lagopus*)
- **Boom:** collared earthstar (*Geastrum triplex*) / devil's cigar (*Chorioactis geaster*)
- **Wall:** hoof fungus (*Fomes fomentarius*) / lion's mane (*Hericium erinaceus*)
- **Bank:** golden oyster (*Pleurotus citrinopileatus*) / penny bun, porcini (*Boletus edulis*)
- **Brood Empress:** bird's nest fungus (Nidulariaceae) / violet coral fungus (*Clavaria zollingeri*)
- **Mould:** green-cracking russula (*Russula virescens*) / orange pore fungus (*Favolaschia calocera*)

Bonus sheet:

- **Bank:** golden chanterelle (*Cantharellus cibarius*)
- **Mould:** true morel (*Morchella esculenta*)

All concepts preserve the cap-as-head anatomy: the eyes sit directly on the fungus and there is no separate face between cap and body.
